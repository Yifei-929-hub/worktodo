# WorkTodo

Windows 上的工作待办软件：管理每天的待办、按时提醒，收工后一键生成发给领导的每日工作日志。数据只保存在本机，断网也能用。

## 下载

**最新版本：[1.0.0](https://github.com/Yifei-929-hub/worktodo/releases/latest)**

打开上面的链接，在页面下方的 **Assets** 里下载 `WorkTodo-Setup-1.0.0.exe`。所有版本见 [Releases](https://github.com/Yifei-929-hub/worktodo/releases)。

支持 64 位 Windows 10 / 11，不需要安装其他运行环境。

## 安装

1. 双击下载的安装包，按向导完成安装。
2. 安装包没有代码签名，Windows 可能提示“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。
3. 安装后桌面和开始菜单会有 WorkTodo 快捷方式。

关闭窗口后程序仍在任务栏右下角的托盘里运行，以便按时提醒；要退出请右键托盘图标，选“退出”。

## 升级

不用先卸载旧版本，直接覆盖安装，数据会保留：

1. 建议先在旧版的“备份与恢复”里点“导出备份”，存到其他位置。
2. 右键托盘图标选“退出”。
3. 下载新版本的安装包并双击安装，安装位置保持原来的。

新版本第一次打开时会自动升级数据，升级后不能再用旧版本打开。

## 卸载

在 Windows 的“设置 → 应用”里卸载 WorkTodo。卸载时可选择是否保留数据，默认保留，以后重新安装仍可使用。您自己导出的备份文件不受影响。

## 功能

- **待办**：标题、日期时间、结束时间、细节描述、完成情况、优先级；“今天 / 未来 / 已完成”三个视图，未完成的显示在“已逾期”；拖动排序；删除后在回收站保留 1 天。
- **提醒**：到点或提前 5 / 15 / 30 分钟弹出 Windows 通知；程序未运行时错过的提醒，下次打开时汇总显示。
- **悬浮窗**：小窗显示今天和逾期的待办，可勾选、添加，可置顶。
- **日历**：月、周、日视图，按时长显示；点空白处新建，拖动改时间和日期，拖下边缘改时长。
- **工作日志**：按当天完成的待办生成，可取舍、调整顺序、改字、补充，一键复制，按日期保存，也能补写过去的日期。格式如下（示例内容）：

  ```text
  11.5
  （1）整理会议纪要。汇总意见，发给项目组。
  （2）参加产品培训。学习产品历史；了解各模块。
  ```

- **备份**：每天自动备份一份，保留最近 7 份；可导出备份文件，换电脑或重装后用它恢复。

## 开发

需要 Node.js 22 或更新版本。

```powershell
npm ci
npm run dev        # 开发运行，数据保存在项目内的 user-data 目录
npm test           # 单元测试
npm run e2e        # 在真实窗口中的检查
npm run dist       # 生成安装包，输出到 dist 目录
```

技术：Electron、TypeScript、React、SQLite（Node 内置）。
